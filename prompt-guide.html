바이브코딩 처음 해 보는 선생님을 위한 따라 하기

수능 응원 웹앱, 프롬프트로 직접 만들어 보기

구글 스티치로 화면을 먼저 그리고, 그 시안을 코딩 도구에 넘겨 수능 응원 웹앱을 처음부터 만들어 봅니다. 단계마다 그대로 복사해 쓸 수 있는 프롬프트를 실었습니다. 완성된 모습은 예시 페이지에서 볼 수 있습니다.

준비물 개인 구글 계정, 코딩 도구 하나(클로드 코드, 안티그래비티, 제미나이 CLI 가운데 하나), GitHub 계정비용 무료 범위에서 할 수 있습니다(도구마다 사용량 한도가 있습니다)

01

만들 것 정하기

한 줄로 말하면 고3에게 주는 선물 페이지 하나입니다. 응원 편지 벽과 수능 날 안내를 탭 다섯 개에 나눠 담습니다.

탭담는 것
응원선생님·후배·부모님이 보낸 편지 벽, 「편지 남기기」 단추
전날 밤가방에서 빼 둘 물건 체크리스트, 아날로그 시계 맞추기, 4교시 순서 카드
아침챙길 것 체크리스트, 고사장 길찾기, 수험표를 잃어버렸을 때 안내
시험 중지금 몇 교시인지, 끝나기까지 남은 시간, 오늘의 시간표(기다리는 가족용)
끝난 뒤4교시가 끝나면 열리는 축하 편지, 정답 공개·성적 통지 일정

처음부터 다 만들려고 하지 마십시오. 화면을 먼저 그리고(2~6장), 코드로 옮긴 뒤(7~8장), 사실을 맞추고(9장), 편지를 연결하고(10장), 배포합니다(11장). 이 순서는 독키피디아 스케치 대백과의 「먼저 그리고 나서 코드로」를 따랐습니다.

02

스티치에 정할 다섯 가지

한 줄로 말하면 대상, 기기, 색, 글꼴, 말투를 먼저 정해 두면 시안이 한 번에 가까워집니다.

정할 것이 웹앱에서 정한 값
대상고3 학생, 기다리는 학부모, 편지를 쓰는 선생님·후배
기기휴대폰 먼저(카톡으로 받은 링크를 엶), PC에서도 보기 좋게
색주 색 #E86E42(테라코타), 바탕 #FFF8F2, 글자 #2E2621
글꼴제목·본문 Noto Sans KR, 편지와 응원 문구는 손글씨 Gaegu
말투다정한 해요체, 단추 글자는 짧게
시작 전에스티치(stitch.withgoogle.com)는 개인 구글 계정으로 들어갑니다. 학교 계정은 막혀 있을 수 있습니다. 같은 문장을 넣어도 결과가 매번 달라지니, 마음에 드는 안이 나오면 바로 확정합니다.
03

첫 화면 뽑기

한 줄로 말하면 응원 탭 한 장부터 뽑습니다. 이름이나 학번 입력칸은 처음부터 넣지 않습니다.

스티치에 이렇게 말하세요 
고3 수험생에게 선물하는 수능 응원 웹앱의 첫 화면을 만들어줘.
- 대상: 고3 학생과 학부모, 선생님. 휴대폰으로 많이 열어.
- 맨 위: "D-9", "수능까지 9일 남았어요", 그 아래 선생님 손글씨 응원 문구 두 줄과 서명 "선생님이".
- 그 아래 탭 다섯 개: 응원, 전날 밤, 아침, 시험 중, 끝난 뒤.
- 본문: "선생님, 후배, 부모님이 보낸 편지" 제목, 넓은 "편지 남기기" 단추, 포스트잇처럼 생긴 편지 카드 세 장.
- 주 색 #E86E42, 바탕 #FFF8F2, 글자 #2E2621. 제목·본문은 Noto Sans KR 16px, 편지와 응원 문구는 손글씨 Gaegu.
- 말투는 다정한 해요체, 단추 글자는 짧게.
- 이름이나 학번 입력칸은 넣지 마.

말투만 바꾸고 싶으면 이렇게 말합니다.

스티치 
화면 구성은 그대로 두고 말투만 바꿔 봐. 버튼 글자를 더 짧게.
04

화면 다섯 장으로 늘리기

한 줄로 말하면 첫 화면을 확정한 뒤 같은 규칙으로 네 장을 더합니다. 다섯 장이 되면 멈춥니다.

스티치 · 확정하기 
이 안으로 고정해. 다음 화면은 이 안의 색과 글꼴과 여백 그대로 만들어줘.
스티치 · 전날 밤 
"전날 밤" 탭 화면을 만들어줘. 위쪽 머리와 탭은 그대로 두고 본문만 바꿔.
- "가방에서 빼 둘 물건" 체크리스트(네모 체크 칸, 확인한 개수 표시)
- 아날로그 시계와 디지털 시각을 함께 보여 주는 "시계 맞추기" 카드
- 탐구 과목을 고르면 4교시 순서가 나오는 "4교시 순서 카드"(입장권 모양)
스티치 · 아침 
"아침" 탭 화면을 만들어줘. 위쪽 머리와 탭은 그대로 두고 본문만 바꿔.
- "챙길 것" 체크리스트
- 고사장 이름 입력칸과 "카카오맵 열기", "네이버 지도 열기" 단추
- "수험표를 잃어버렸다면" 안내 상자(옅은 분홍)
스티치 · 시험 중 
"시험 중" 탭 화면을 만들어줘. 기다리는 가족이 보는 화면이야.
- 맨 위에 "지금 몇 교시"를 크게 보여 주는 카드와 끝나기까지 남은 시간 막대
- 그 아래 "오늘의 시간표" 세로 타임라인. 지금 교시는 주 색으로 표시
스티치 · 끝난 뒤 
"끝난 뒤" 탭 화면을 만들어줘.
- 시험이 끝나야 열리는 축하 편지. 열리기 전에는 봉인된 편지 봉투와 "11월 19일 16:37에 열려요"
- "시험 끝나고 할 일" 목록(날짜와 할 일)
시안의 날짜·시각·규정 글자는 믿지 마십시오스티치는 그럴듯한 시험 정보를 지어 넣습니다. 시안은 모양만 보고, 글자는 9장에서 공고와 맞춥니다.
05

고칠 곳만 고치기

한 줄로 말하면 전체를 다시 뽑지 말고, 한 번에 한 곳만 짚어서 고칩니다.

우리가 겪은 일처음 시안은 맨 위가 분홍빛 그라데이션이었습니다. 보자마자 "AI가 만든 것 같다"는 느낌이 들었습니다. 그라데이션을 걷어 내고 평평한 편지지 색에 우체국 소인 도장을 찍었더니, 선물 같은 느낌이 살아났습니다.
스티치 · 먼저 지적만 받기 
이 화면에서 AI가 만든 티가 나는 곳을 짚어서 목록으로만 알려줘. 고치지는 마.
스티치 · 한 곳만 고치기 
맨 위의 그라데이션과 번지는 빛 효과를 걷어 내고, 평평한 편지지 색(#FFF1E4) 한 가지로 바꿔줘. 오른쪽 위에 "11.19 수능 응원"이라고 찍힌 우체국 소인 도장을 옅은 주 색 선으로 그려줘. 다른 곳은 그대로 둬.
스티치 · 이모지 걷어 내기 
제목 앞의 이모지를 빼고, 같은 굵기의 선 아이콘으로 바꿔줘. 다른 곳은 그대로 둬.
요령화면의 요소를 눌러 그 부분만 다시 만들 수 있습니다. 여러 곳을 고칠 때는 화면에 주석을 남겨 한꺼번에 적습니다. 말로 고쳤다면 중요한 결정은 따로 글로 적어 두십시오.
06

규칙 한 장(DESIGN.md)

한 줄로 말하면 다섯 화면에 반복되는 규칙만 한 장으로 뽑고, "하지 말 것"은 사람이 직접 적습니다.

스티치 
지금 다섯 화면에서 반복되는 규칙만 뽑아서 한 장으로 정리해줘. 한 화면에만 쓰인 값은 빼고.

뽑아 준 DESIGN.md 끝에 아래 「하지 말 것」을 직접 붙입니다. 이 줄이 없으면 코딩 도구가 평균적인 값을 채워 넣습니다.

DESIGN.md에 붙여 넣을 것 
## 하지 말 것
- 그라데이션, 빛 번짐, 반짝이 효과를 쓰지 않는다. 머리 바탕은 평평한 #FFF1E4 한 가지.
- 제목 앞에 이모지를 넣지 않는다. 아이콘은 같은 굵기의 선 아이콘만 쓴다.
- 어두운 화면(다크 모드)을 따로 만들지 않는다. 어떤 설정에서 열어도 밝은 색 하나로 보인다.
- 이름, 학번, 전화번호 입력칸을 만들지 않는다.
- 시험 날짜, 시각, 반입 물품, 규정을 지어서 넣지 않는다. 공고에 있는 문장만 쓴다.
- 카드마다 다른 모서리 둥글기와 그림자를 쓰지 않는다.
07

코딩 도구로 넘기기

한 줄로 말하면 화면 다섯 장, 규칙 한 장, 탭 이동 정보를 함께 넘기고, 첫 지시는 "다른 곳 목록만 알려 줘"입니다.

클로드 코드, 안티그래비티, 제미나이 CLI는 스티치 시안을 직접 읽을 수 있습니다(MCP 연결). 연결이 어렵다면 스티치에서 화면 코드와 DESIGN.md를 내려받아 빈 폴더에 넣고, 코딩 도구를 그 폴더에서 엽니다. 스티치가 준 코드는 시안이라 그대로 쓰지 않고 대조용으로만 씁니다.

코딩 도구 · 뼈대 만들기 
스티치 시안 다섯 화면과 DESIGN.md를 보고, index.html 한 파일로 된 웹페이지를 만들어줘.
- HTML, CSS, 자바스크립트만 쓰고 프레임워크나 빌드 도구는 쓰지 마.
- 탭 다섯 개(응원, 전날 밤, 아침, 시험 중, 끝난 뒤)는 한 페이지 안에서 바뀌게 해.
- 휴대폰 폭 390px을 먼저 맞추고, 900px 이상에서는 머리를 좌우로 나누고 카드를 두 단으로 놓아줘.
- 시험 날짜·시각·규정 글자는 아직 넣지 말고 "(공고 확인)"으로 비워 둬.
- DESIGN.md의 "하지 말 것"을 지켜. 다르게 만들 이유가 생기면 만들지 말고 먼저 물어봐.
코딩 도구 · 만든 뒤 첫 지시 
지금 만든 화면과 시안이 다른 곳을 목록으로 알려줘. 고치지는 마.

목록을 보고 고칠 것만 골라 "1번, 3번만 고쳐줘"처럼 말합니다.

08

기능 하나씩 붙이기

한 줄로 말하면 한 번에 기능 하나만 시키고, 고친 뒤에는 휴대폰 폭에서 직접 눌러 봅니다.

탭이 시각에 맞춰 바뀌게

코딩 도구 
페이지를 열면 한국 시간 기준으로 맞는 탭이 먼저 열리게 해줘.
- 11월 18일 18시 전: 응원 / 18시부터 19일 5시: 전날 밤 / 5시부터 8시 40분: 아침 / 8시 40분부터 16시 37분: 시험 중 / 그 뒤: 끝난 뒤
- 열어 둔 채로 경계 시각이 지나면 자동으로 넘어가되, 학생이 다른 탭을 직접 보고 있으면 넘기지 마.
- 기기의 시간대 설정과 상관없이 한국 시간으로 계산해.
- 탭을 눌러도 주소 끝에 탭 이름이 남지 않게 해.
다 만들면 날짜를 바꿔 가며 확인할 수 있는 시험 방법도 알려줘.

D-day와 시계

코딩 도구 
맨 위 D-day는 한국 시간 날짜로 계산해. 수능 당일은 "D-DAY", 지난 뒤에는 "수고했어요"로 바꿔줘.
"전날 밤" 탭의 아날로그 시계는 한국 표준시를 초 단위로 보여 줘. 기기 시계가 서버 시각과 2초 넘게 다르면 서버 시각에 맞춰 보여 주고 그 사실을 안내해줘.

체크리스트와 고른 과목 저장

코딩 도구 
체크리스트 체크, 고른 탐구 과목, 입력한 고사장 이름은 이 기기의 로컬스토리지에만 저장해. 서버로 보내지 마. 저장이 막힌 환경(시크릿 모드 등)에서도 페이지는 정상으로 열리게 해.

4교시 순서 카드

코딩 도구 
탐구 영역(사회·과학탐구 2과목/1과목, 직업탐구 2과목/1과목, 탐구 안 봄)과 과목을 고르면 4교시 순서 카드를 보여 줘.
- 시간은 9장의 사실 자료 표를 그대로 써.
- 사회·과학탐구 2과목은 공고에 나온 과목 순서대로 제1·제2선택을 정리하고, "수험표와 책상 스티커의 순서를 따르라"는 안내를 붙여.
- 직업탐구 2과목은 "성공적인 직업생활"이 제1선택이야.

PC 화면

코딩 도구 
900px 이상 넓은 화면을 다듬어줘. 머리는 왼쪽에 D-day, 오른쪽에 손글씨 응원 문구. 편지는 3열, 전날 밤·아침 카드는 2단, 시험 중은 왼쪽에 "지금 몇 교시" 카드(스크롤해도 따라오게), 오른쪽에 시간표. 휴대폰 화면은 바꾸지 마.
09

수능 정보 대조하기

한 줄로 말하면 아이들에게 틀린 정보가 가면 안 됩니다. 공고 원문을 주고 한 줄씩 대조시킨 뒤, 사람이 한 번 더 봅니다.

우리가 겪은 일스티치 시안에는 수험표 재발급 시각이 "07:30까지"로, 3교시 영어가 "13:07~14:20(73분)"으로 들어가 있었습니다. 교육부 유의사항에는 재발급이 "08:00까지", 공고에는 영어가 "13:10~14:20(70분)"으로 되어 있습니다. 그럴듯해서 그냥 넘어가기 쉽습니다.

한국교육과정평가원 누리집(kice.re.kr, suneung.re.kr)에서 「2027학년도 대학수학능력시험 시행세부계획 공고」를 내려받고, 교육부의 수험생 유의사항 보도자료를 함께 준비합니다.

코딩 도구 · 대조만 시키기 
첨부한 「2027학년도 대학수학능력시험 시행세부계획 공고」와 교육부 수험생 유의사항을 기준으로, 페이지에 들어간 날짜·시각·분 수·과목명·물품·규정 문구를 한 줄씩 대조해줘.
- 다른 곳, 근거 없이 단정한 곳, 수험생이 잘못 이해할 수 있는 곳을 표로만 알려줘.
- 칸은 "페이지 문구 / 근거 문장 / 고칠 문장"으로.
- 고치지는 마.

다른 AI에게 같은 일을 한 번 더 시키면 놓친 곳을 잡을 수 있습니다. 다만 다른 AI의 지적도 공고 원문으로 다시 확인하십시오. 우리 경우 한 AI는 성적 통지일에 "근거가 없다"고 했는데, 실제로는 공고 11쪽에 있었습니다.

편지 받기(설문·시트)

한 줄로 말하면 설문과 응답 시트는 템플릿 사본으로 받고, 페이지에는 "체크한 편지만 읽어 오는 기능"만 시킵니다.

설문, 응답 시트, 「반영」 체크 칸, 「공개용」 탭 수식은 이미 만들어 둔 템플릿이 있습니다. 사용설명서 1~3단계대로 사본을 만들고 설문을 만든 뒤, 「공개용」 탭만 웹에 게시합니다. 그 주소를 페이지에 연결하는 부분만 코딩 도구에 시킵니다.

코딩 도구 
구글 시트 「공개용」 탭을 웹에 게시한 CSV 주소를 2분마다 읽어서 응원 벽에 붙여줘. 주소는 따로 config.js 파일에 넣어 둘 수 있게 해.
- 열은 from(보낸 사람), text(편지), type(before/after), group(teacher/junior/parent/other)이야.
- type이 after인 편지는 11월 19일 16:37 전까지 "끝난 뒤" 탭에서 봉투로 잠가 둬.
- 쉼표, 따옴표, 줄바꿈이 섞인 CSV도 제대로 읽어.
- 편지 글은 반드시 글자로만 넣고 HTML로 해석하지 마.
- 보낸 사람에 따라 편지지 색을 다르게 하고, 위에 "전체·선생님·후배·부모님·그 밖" 골라 보기 단추를 둬. 편지가 없는 분류의 단추는 숨겨.
- 반영된 편지가 하나도 없으면 "예시 편지예요"라고 표시한 예시 편지를 보여 주고, 진짜 편지가 오면 예시는 사라지게 해.
개인정보웹에 게시할 때는 전체 문서가 아니라 「공개용」 탭 하나만 고릅니다. 전체를 게시하면 체크하지 않은 편지까지 공개됩니다. 설문에서 이메일은 수집하지 않습니다.

한 줄로 말하면 GitHub Pages로 무료 배포하고, 카톡에서 링크가 예쁘게 보이도록 미리보기를 만듭니다.

코딩 도구 · 아이콘과 카톡 미리보기 
편지 봉투 모양의 파비콘(svg, 192px png, 아이폰용 180px png)과 카톡 공유 미리보기를 만들어줘.
- 미리보기 그림은 1200×630, 페이지와 같은 색과 글꼴로.
- 제목: 수능 날, 곁에서 응원할게요
- 설명: 선생님과 후배, 부모님이 쓴 응원 편지를 읽어 보세요. 수능 날 준비물과 시간표도 함께 담았어요.
코딩 도구 · 배포 
이 폴더를 GitHub 새 공개 저장소에 올리고 GitHub Pages를 켜려고 해. 올라갈 파일 목록을 먼저 보여 주고, 개인정보나 키가 섞였는지 확인해줘. 그다음 내가 따라 할 순서를 단계별로 알려줘.
배포한 뒤 확인할 것
  • 휴대폰과 PC에서 다섯 탭을 모두 눌러 보기
  • 시트에서 편지 하나를 「반영」 체크하고 5~10분 뒤 응원 벽에 뜨는지 보기
  • 카톡으로 링크를 보내 미리보기가 뜨는지 보기(옛 미리보기가 나오면 주소 끝에 ?v=2)
  • 카톡 안에서 열었을 때 색이 어둡게 바뀌지 않는지 보기

증상까닭과 해결
시안의 시험 정보가 그럴듯한데 틀림스티치가 지어 넣은 것입니다. 9장대로 공고와 대조합니다.
카톡에서 열면 색이 어둡게 나옴다크 모드 색이 켜진 것입니다. "어떤 설정에서 열어도 밝은 색 하나로 보이게 해줘"라고 시킵니다.
내 컴퓨터에서 열면 편지를 못 불러옴파일로 열면 구글이 막습니다. 배포한 주소에서 확인합니다.
카톡 미리보기가 옛것으로 나옴카톡이 예전 미리보기를 기억하고 있습니다. 주소 끝에 ?v=2를 붙여 보냅니다.
체크한 편지가 안 뜸웹 게시가 반영되는 데 5분쯤 걸리고, 페이지는 2분마다 다시 읽습니다. 10분 넘게 안 뜨면 「공개용」 탭을 게시했는지 확인합니다.
시트를 복사했는데 설문이 없음보기 권한으로 복사하면 설문은 따라오지 않습니다. 템플릿 시트의 메뉴 「수능 응원 → 설문 만들기」를 씁니다.
AI가 시키지 않은 것까지 고침"고치지는 마", "다른 곳은 그대로 둬"를 붙이고, 한 번에 한 가지만 시킵니다.
